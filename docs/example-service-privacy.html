Example NFC Service Privacy Notice

Notice version: 2026-07-29
Operator: Example Service Operator

This notice belongs only to the repository's demonstration reader configuration. Do not use the example identity or metadata for a production service.

Requested data and purposes

The example service requests an alias to display a chosen name, a random service-specific user ID to distinguish its local account, and a service-specific public authentication key to verify authentication signatures. It does not request any other field.

Storage and transfer

Registration and authentication payloads are authenticated and encrypted directly between the phone and this example service. The reference reader stores the approved fields, its service session secret, and registration time in its local SQLite database. It includes no analytics or remote backend.

Deletion

Delete the corresponding row from the reference reader's local registered_devices_v2 table, or delete its local auth.db file to remove all example-service registrations. Deleting the registration on the phone does not remove this service-side copy.

Contact

Questions about this demonstration service can be submitted through the project issue tracker. A real service must replace this notice and contact with its own.
